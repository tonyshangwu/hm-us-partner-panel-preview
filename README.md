仓库公开是为了让链接不用登录就能打开。搜索引擎已用 `noindex` 和 `robots.txt` 声明不要收录。

## 如何下线

在 GitHub 打开本仓库，选择 Settings → Danger zone → Delete this repository，删除后链接即失效。也可以只关闭 Settings → Pages，页面会停止发布，仓库仍保留。
